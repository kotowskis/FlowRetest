# Audyt tygodni 1 do 8

Przegląd całego repozytorium po commicie `01b4e14` (tydzień 8, wersja `0.3.0-next.1`). Pięć niezależnych przeglądów: rdzeń odtwarzania (klasyfikator, rewriter, role), diff z normalizacją i redakcją, CLI z sandboxem, proxy ze schematami i CI, zgodność z planem i dokumentacją. Większość znalezisk potwierdzono skryptami na źródłach; te, które sprawdzono tylko czytaniem kodu, mają dopisek „niesprawdzone”. Punkt wyjścia: `npm run verify` przechodzi, testy jednostkowe są zielone, ale żaden z nich nie pokrywa poniższych przypadków.

Kolumna „Stan” pokazuje, co już poprawiono. Kolejność napraw: P0, potem diff, potem prywatność i Action, na końcu e2e przez prawdziwe `run` i dokumentacja.

## Testy

- E2E katalogu idzie przez `runSpikeDay7`, nie przez `run`, więc produkcyjna ścieżka z `executeBatch` nie ma testu.
- Żaden test nie wykonuje wygenerowanego `jsCode`.
- Test baseline'u „round-trips” nie serializuje do JSON i z powrotem.
- Brak testów na: zmianę ID w ścieżce, duże ciało, HTTP Request v1, pominiętą domyślną operację, polskie nazwy węzłów, redakcję znaków spoza ASCII.

## Zgodność z planem

Brakuje: `--stub` i `stubs.yml`, `volatile.json`, flag globalnych (`--json`, `--verbose`, `--no-color`, `--cwd`), `diff --format`, `sandbox export --compose`, eslint, c8 z progiem 80% i `npm audit` w CI, sekcji „Engine differences” w `upgrade-check`, pól raportu `static` i `sandbox`. `sealed: true` jest wpisane na sztywno, więc zdanie „0 requests left the sandbox” niczego nie sprawdza.

Odstępstwa bez ADR ani wpisu w dzienniku: `tsc` zamiast jednego bundla, katalog regresji jako kod zamiast `catalog/` z `expected.json`, `--stabilize` domyślnie wyłączone, zmienione nazwy flag (`--keep`, `accept --cases`, `redact` bez `--fixtures`), Node 22.5 zamiast 20, macierz e2e bez wersji 2.20 i 2.30, komendy spike'u w produkcyjnym CLI.

Nieaktualne dokumenty:

- główny `README.md` podaje wersję 0.1 i jest po polsku, a plan wymaga angielskiego;
- `packages/cli/README.md` opisuje kody wyjścia, BLOCKED i `--stabilize` niezgodnie z kodem;
- `docs/dziennik.md` twierdzi, że `release.yml` wypełnia digest;
- `docs/formaty/README.md` twierdzi, że każdy plik jest walidowany schematem (walidowana jest tylko konfiguracja) i że raport zredagowany ma ten sam kształt;
- `docs/integracje.md` podaje kody 0 do 5 i odsyła do punktu 6.6;
- ADR 0001 pisze BLOCKED tam, gdzie jest SKIPPED; ADR 0003 ma nieaktualne „do potwierdzenia”;
- `docs/bramka-5.md` pisze o 15 zielonych przypadkach, a test szedł ścieżką spike'u.
